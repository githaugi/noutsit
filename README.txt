Boards – Android APK build
1. Create a new GitHub repository (private is fine) and upload ALL files in this folder, keeping the structure.
   Check that .github/workflows/build-apk.yml exists in the repo. If not, create it via Add file > Create new file
   and paste the contents of WORKFLOW-COPY.txt.
2. Open the Actions tab and wait for "Build APK" to finish (a few minutes). Or press Run workflow.
3. Open the repo's Releases page on your phone, download app-debug.apk and install it.
